## Welcome to Clifacet

Welcome to the **Clifacet** documentation site built with [Fumadocs](https://fumadocs.dev).

Clifacet is a Rust CLI framework that decouples your command logic from terminal presentation. Define your commands once on a declarative controller, and execute noninteractively (plain text or `--json`), through interactive Inquire prompts, in a full-screen Ratatui terminal UI, or over Model Context Protocol (MCP) stdio.

<Callout type="info">
Clifacet runs commands across four presentation modes: noninteractive (flags in, output out), interactive (a questionnaire on a terminal), TUI (a full-screen form), and MCP (a JSON-RPC 2.0 tool server). A run resolves to the lowest mode that can answer, unless the user or application requests otherwise.
</Callout>

## Terminal Execution Modes

<Tabs items={["Noninteractive", "Structured JSON", "Interactive Dialog", "Full-Screen TUI", "MCP Tool Server"]}>
  <Tab value="Noninteractive">
    Provide arguments directly via flags. Standard output and error streams handle results and diagnostics.
    ```sh
    cargo run -p clifacet-example -- --name ada --repeat 2
    ```
  </Tab>
  <Tab value="Structured JSON">
    Emit valid machine-readable JSON on stdout and diagnostic failure envelopes on stderr.
    ```sh
    cargo run -p clifacet-example -- --name ada --repeat 2 --json
    ```
  </Tab>
  <Tab value="Interactive Dialog">
    Missing arguments trigger conversational Inquire questionnaires with live validation.
    ```sh
    cargo run -p clifacet-example -- --interactive
    ```
  </Tab>
  <Tab value="Full-Screen TUI">
    Presents an automated or custom Ratatui form field widget on the alternate terminal screen.
    ```sh
    cargo run -p clifacet-example -- --tui
    ```
  </Tab>
  <Tab value="MCP Tool Server">
    Runs a Model Context Protocol tool server over JSON-RPC 2.0 stdio with async tool dispatch and progress streaming.
    ```sh
    cargo run -p clifacet-example -- mcp
    ```
  </Tab>
</Tabs>
