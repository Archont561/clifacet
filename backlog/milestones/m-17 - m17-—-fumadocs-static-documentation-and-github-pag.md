## Description

Adopt the Archont561/* documentation standard: static documentation generated by Fumadocs (Next.js static export) from MDX files leveraging Fumadocs UI components (Callouts, Cards, Tabs, Steps, Accordions), automated publishing to GitHub Pages via .github/workflows/pages.yml, and integrated with repository quality gates (check-docs, Vale prose linting, snippet compilation).
