# Backlog

Use for project planning, task work and acceptance criteria. The canonical
store is `backlog/`; use `pixi run --frozen backlog -- <command>` to list,
search, create or update records so IDs and references stay consistent. Run
`doctor` after structural changes. Read relevant decisions and task criteria
before implementing. Report incomplete or unverified criteria honestly. Never
close tasks or change scope without maintainer authorization.
