# Writing for agents

Give each instruction an explicit trigger, context, ordered action and
observable completion condition. Link to the canonical decision rather than
copying it. Distinguish required rules from suggestions and mark uncertain
claims. Keep always-loaded instructions short; put specialist details in a
skill. Verify paths and commands exist and do not grant extra permissions.
